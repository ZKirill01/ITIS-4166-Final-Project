The Task Manager API is a RESTful API built on Express, Prisma ORM, and PostgreSQL. It allows users to create and manage their daily tasks by organizing them into projects and categories. The API uses JWT-based authentication, which allows it to authenticate users and then verify authorization when sending API requests.
